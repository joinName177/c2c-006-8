# c2c-006 · 决策后悔模拟器

Vue 3 + TypeScript + Vite 纯前端决策反思工具。支持录入 2–4 个方案、设置稳定/成长/自由/金钱权重、生成 1/5/10 年后悔指数与预演卡，并以 SVG 曲线比较“最不后悔”方向。可在同一条曲线上增删 2–4、6–9 等中间观察年，查看规则推算的中间时点。

## 观察年份与插值规则

- **时间锚点**：1、5、10 年是规则直接定义系数的锚点，不可移除；三个锚点的分值、预演卡、总分与加入观察年之前逐位一致。
- **中间年怎么来**：对四个价值维度的时间系数，在相邻锚点区间 `[1,5]`、`[5,10]` 内做**分段线性插值**，再代入原评分公式重新计算，因此每个中间点都有真实的四维拆解，不是给旧分数换标签。不可逆成本本身是年份的线性函数，中间年自然落在同一直线上。
- **为什么不是平滑曲线**：只有三个锚点时样条平滑没有数据依据，还可能产生规则从未给出的越界系数；线性插值可手工复核、锚点严格恒等、不会 overshoot。
- **锚点之外**：规则只覆盖 1–10 的整数年。超出范围或非整数输入会被拒绝，**不做任何外推**（不常数延拓、不顺势延伸）。
- **观察年 ≠ 总分汇合年**：观察年只决定曲线上画哪些点；总分始终只由 1/5/10 锚点按 30% / 40% / 30% 汇合，新增观察点不改变排名与推荐。
- **确定性归一化**：重复年份、乱序输入都会先“合并锚点 → 去重 → 升序 → 丢弃非法值”，任何输入只产生同一条曲线。
- **保存与打印同源**：观察年随案例存入 localStorage，重开后沿用同一套时间设置；已存分析若与当前年份不一致（或来自旧版本）会被丢弃并提示重新推演。打印报告就是当前结果：实心点=锚点，空心点=插值推算，并附“推算来自规则、不是对未来预测”的说明。

## 架构

- `src/core`：领域模型、输入校验、权重归一化、后悔评分、预演与安全提示
- `src/ports`：案例仓储和打印端口
- `src/adapters`：localStorage 与浏览器打印实现
- `src/ui`：Vue 控制器、分步组件和原生 CSS

## 运行

```bash
npm install
npm run dev
npm run build
docker compose up --build
```

Docker 部署访问 `http://localhost:8106`。案例仅保存在当前浏览器。

指数是透明、确定性的本地规则：分别计算 1、5、10 年价值偏差和可逆性成本，再按 30% / 40% / 30% 合成总分。它不预测真实未来，也不替代医疗、法律或投资专业意见。
