# c2c-006 · 决策后悔模拟器

Vue 3 + TypeScript + Vite 纯前端决策反思工具。支持录入 2–4 个方案、设置稳定/成长/自由/金钱权重、生成 1/5/10 年后悔指数与预演卡，并以 SVG 曲线比较“最不后悔”方向。

## 架构

- `src/core`：领域模型、输入校验、权重归一化、后悔评分、预演与安全提示
- `src/ports`：案例仓储和打印端口
- `src/adapters`：localStorage 与浏览器打印实现
- `src/ui`：Vue 控制器、分步组件和原生 CSS

## 运行

```bash
npm install
npm run dev
npm run build
docker compose up --build
```

Docker 部署访问 `http://localhost:8106`。案例仅保存在当前浏览器。

指数是透明、确定性的本地规则：分别计算 1、5、10 年价值偏差和可逆性成本，再按 30% / 40% / 30% 合成总分。它不预测真实未来，也不替代医疗、法律或投资专业意见。

## 观察年份

除 1 / 5 / 10 年三个固定锚点外，可在录入页把 2–9 中任意年份加入曲线观察中间时点：

- 中间年份的时间系数由相邻锚点**分段线性插值**得到（如第 3 年系数 = 第 1 年与第 5 年系数的中点），可逆性成本按年份线性代入；锚点年份仍直接查表，相同输入下结果与引入观察年之前完全一致。
- 观察范围限定在锚点覆盖的 1–10 年内，**不做外推**；重复、乱序或越界的年份输入会被归一化（去重、排序、剔除锚点与越界值），曲线横坐标按年份等比分布。
- 观察年份以空心点显示，**不参与总分与预演卡**——总分始终只由 1 / 5 / 10 年锚点按 30% / 40% / 30% 加权，因此增删观察年不会改变排名与建议。
- 观察年是规则在锚点之间的推算值，不是对未来的预测。时间设置随案例保存，重开与打印使用同一套时间线。
